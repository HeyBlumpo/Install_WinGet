# Install WinGet
Simple one-line install scripts for WinGet and Chocolatey

To run them, run PowerShell as admin and paste one of the following commands:

#### Install WinGet
```
irm "[https://spoo.me/blumpo_winget](https://raw.githubusercontent.com/HeyBlumpo/Install_WinGet/refs/heads/main/source/install_winget.ps1)" | iex
```

#### Install Chocolatey
```
irm "[https://spoo.me/blumpo_choco](https://raw.githubusercontent.com/HeyBlumpo/Install_WinGet/refs/heads/main/source/install_choco.ps1)" | iex
```
